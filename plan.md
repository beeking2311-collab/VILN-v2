# Jack — 3D Creator Portfolio Plan

## Implementation
- Build a single root page in React + TypeScript + Vite with Tailwind CSS, Framer Motion, and Lucide React.
- Keep the visual system faithful to the approved brief: near-black canvas, cool silver gradient typography, Kanit, full-bleed editorial composition, white services interlude, and magenta/orange contact accent.
- Break the interface into `HeroSection`, `MarqueeSection`, `AboutSection`, `ServicesSection`, and `ProjectsSection` plus reusable `FadeIn`, `Magnet`, `AnimatedText`, `ContactButton`, and `LiveProjectButton` components.
- Use the supplied remote image URLs unchanged. The page has no backend, auth, database, or user data.
- Serve `/manus-routes.json` as the route manifest for the single `/` route.

## Design direction
- **Design movement:** cinematic digital brutalism with soft 3D editorial polish.
- **Core principles:** oversized type, intentional negative space, tactile image surfaces, and motion that rewards scrolling.
- **Color philosophy:** #0C0C0C gives the work a gallery-like stage; silver gradients make the typography feel lit; the bright white services panel creates a hard visual cut; the magenta-to-orange CTA is the signature spark.
- **Layout paradigm:** stacked full-bleed scenes, alternating dark/light chapters, and sticky project cards instead of a conventional card grid.
- **Signature elements:** cool-metal gradient headings, scroll-reactive horizontal image ribbons, and rounded image capsules with thick borders.
- **Interaction philosophy:** cursor movement feels magnetic and physical, while scroll-driven reveals keep the portfolio feeling like an active reel.
- **Animation:** use soft spring-like entrances, low-friction transform transitions, character-level opacity reveals, and sticky scale-down stacking for projects.
- **Typography system:** Kanit 300–900; black uppercase display type for section names; medium uppercase labels; light, widely tracked supporting copy.
- **Brand essence:** Jack turns ambitious ideas into tactile 3D worlds for brands that want to be impossible to forget. Personality: cinematic, precise, electric.
- **Brand voice:** direct, visual, self-assured. Example lines: “Crafting the kind of work people remember.” and “Let’s build something incredible together.”
- **Wordmark concept:** a lowercase `jack` wordmark with a stretched terminal on the `k`, echoing the hero’s horizontal energy.
- **Signature brand color:** electric orchid `#B600A8`.
